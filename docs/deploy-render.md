# Deploy Garden to Render

## Prerequisites

- Code pushed to GitHub (private repo `heribish/garden`)
- [Supabase](supabase-setup.md) database with a newly generated, tested connection string
- [Render](https://render.com) account (free tier works)

> **Launch gate:** This repository currently keeps catalog, orders, dispatch,
> support, and ledger data in process memory. Do not make the service public
> until the durable-commerce persistence work is complete and verified. A Render
> restart would otherwise discard that operational data.

## Steps

1. **Push to GitHub** (already done if you ran `git push origin main`):
   ```powershell
   .\scripts\publish.ps1
   ```
   Repo: https://github.com/heribish/Garden

2. **Create Render Web Service**
   - Dashboard → **New +** → **Blueprint**
   - Connect GitHub account and select `heribish/Garden`
   - Render reads [`render.yaml`](../render.yaml) automatically

3. **Set required secrets in Render** (Environment tab or Blueprint prompt)
   - `DATABASE_URL` — Supabase **Session pooler** URI (port `6543`, not direct `5432`)
   - `ALLOWED_ADMIN_EMAILS` — `heribish@gmail.com`
   - `PGSSL` — `1` (already in blueprint)
   - `WEBHOOK_SECRET` — auto-generated by Render
   - `WALLET_PAYMENTS_ENABLED` — `0` (already in blueprint)

4. **Deploy**
   - Build runs `npm install && npm run migrate:commerce` then starts with `npm start`
   - Health check: `/api/health`
   - First deploy **fails** if `DATABASE_URL` is missing or wrong — fix in Environment and redeploy

5. **Post-deploy (once)**
   ```powershell
   $env:DATABASE_URL = "<your-production-pooler-uri>"
   $env:PGSSL = "1"
   npm run create:admin -- --email heribish@gmail.com --password "your-strong-password" --name "Heribish"
   ```
   Then sign in at `https://YOUR-APP.onrender.com/shop` and open `/admin`.

6. **Verify**
   - Shop loads, sign-up/sign-in works
   - Support chat sends and admin can reply
   - Follow [public-launch-checklist.md](public-launch-checklist.md)

## Environment variables (production)

| Variable | Value |
|----------|-------|
| `NODE_ENV` | `production` |
| `ENABLE_DEV_TOOLS` | `0` |
| `DATABASE_URL` | Supabase connection string |
| `WEBHOOK_SECRET` | Strong random secret |
| `PORT` | `3780` (Render sets automatically) |
